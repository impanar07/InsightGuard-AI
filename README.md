# InsightGuard AI

## Trust-Aware Decision Robustness System for Business Analytics

InsightGuard AI is an AI-assisted data analytics system that evaluates whether business decisions remain reliable when the underlying data contains quality issues.

Instead of only measuring data quality, the system:

- Detects data quality issues
- Identifies affected business opportunities
- Generates multiple plausible data repair scenarios
- Re-runs business analytics for each scenario
- Compares the resulting decisions
- Calculates a Decision Robustness Score
- Provides an AI-assisted explanation and recommendation

## Core Question

> Can we trust a business decision even when the underlying data is imperfect?
